# Guruh boshqaruvi (davomat, to'lovlar, o'quvchilar)

Test saytingiz bilan bir xil texnologiya: oddiy sayt fayllari (GitHub Pages) + Supabase bazasi.

## O'rnatish
1. Supabase → SQL Editor → New query: `schema.sql` ni to'liq qo'yib Run. (Eski jadvallarga tegmaydi, faqat `mg_` bilan boshlanadigan yangilari qo'shiladi.)
2. Yangi GitHub repo yarating (masalan `guruhlar`), shu papkadagi hamma fayllarni yuklang. Settings → Pages → Branch: main → Save.
3. Kirish: Supabase'dagi o'qituvchi email va parolingiz (test saytdagi bilan bir xil).
4. Supabase kaliti bo'sh bo'lsa sayt DEMO rejimda (faqat shu brauzerda) ishlaydi.

## Kabinet
Har o'quvchiga 6 belgili shaxsiy kod beriladi. O'quvchi sahifasida «Havolani nusxalash» tugmasi bor: havola `.../#/me/KOD`. Ota-ona yoki o'quvchi shu havola orqali faqat O'Z davomati va to'lovlarini ko'radi.
